# echo 要件定義（v1）

2026-11-21 版。声を出せない人のための読み上げ Web アプリ。

## 1. 目的

声を出せない人が、**相手と同じ速さで対面の会話に参加できる**ようにする。
打った言葉や決まった言葉を、すぐに・確実に・その人の声として出す。

## 2. 利用者

| | 利用者 | v1 |
|---|---|---|
| A | 体は動き、文字も打てるが、声を出さない／出せない人（場面緘黙、喉頭を摘出した人、声帯の手術後で声を休めている人、自分の意思で話さない人など） | **中心** |
| B | A の人が、騒がしい場所や聞こえにくい相手と話す場面 | **中心** |
| C | 手も動かしにくい人（ALS など。スイッチ操作・視線入力が要る） | 対象外 |
| D | 言葉そのものが出にくい人（失語症、発話しない自閉症など。絵や記号で選ぶ AAC が要る） | 対象外 |

ペルソナ：スマホで素早く文字を打てる。相手の声は聞こえる。外出先（お店・病院・タクシー・職場）で、知らない人とも話す。会話の間が空くことと、目立ちすぎることを気にしている。

## 3. 場面

1. **対面の会話**：打って、すぐ声にする。相手の返事を聞いて、また打つ
2. **決まったやりとり**：お店・病院・タクシーで「はい」「お願いします」「領収書ください」をすぐ出す
3. **最初のひと言**：「声が出せないので、これで話します」
4. **緊急**：「助けてください」「救急車を呼んでください」
5. **電波がない場所**：地下・病院の中・機内モード

対象外の場面：電話（Web アプリから通話に声を流すことはできない）。

## 4. 機能要件（v1）

### F1 打って話す
- 入力欄に打って「話す」か Enter で、すぐに読み上げる
- 読み上げ中は止められる（「止める」、Esc）
- Shift+Enter は改行。日本語入力の変換を確定する Enter では話さない。空では何もしない
- 長い文は文ごとに区切って順に読む（Chrome は長文を途中で止めることがあるため）
- 入力欄と「話す」は、画面の下側（親指が届く位置）に置く

**受け入れ基準**：打ち終えてから「話す」を押すまでの操作が 1 回で済む。読み上げが始まると、入力欄は空に戻る。200 文字の文が最後まで読まれる。

### F2 よく使う言葉（場面ごと）
- 1 タップで話す
- 場面ごとのまとまり（タブ）を持つ。初期値は「返事」「あいさつ」「お店」「病院」「移動」「緊急」と、それぞれに数個の言葉
- 言葉の追加・削除・並べ替えができる。場面（タブ）も追加・名前変更・削除できる
- 履歴や入力中の文から、1 回の操作で「よく使う言葉」に入れられる
- 最後に開いていた場面を覚えている

**受け入れ基準**：アプリを開いてから、よく使う言葉を話すまで 1 タップ（場面を切り替えても 2 タップ）。追加した言葉は、再読み込みしても残っている。

### F3 履歴
- 話した言葉を新しい順に残す（最大 100 件。同じ言葉は先頭へ移す）
- 押すともう一度話す。1 件ずつ・すべて消せる
- 自分が話した言葉として、チャットの吹き出しで右に寄せて並べる。15 分以上あいたら時刻を挟む
- 操作（よく使う言葉に入れる・見せる・消す）は、最後に話した行の下にだけ出す。ほかの行は、押して話すとその行の下に移る（行ごとにアイコンや ⋯ を並べない）

### F4 声の設定
- 声（端末に入っている日本語の声）・速さ・高さ・音量を選べる。選ぶと試しに話す
- 音量は 10〜100%。100% が端末の音量での最大（Web Speech API は端末の音量より大きくできない）。うるさい場所では端末の音量を上げるよう、設定の中で案内する。下げているときは入力欄の横に表示する
- 「自分の声」として保存し、いつも同じ声で話す
- いまの声と速さが、入力欄の横にいつも見えている

### F5 書き出し・読み込み
- よく使う言葉・場面・声の設定・（選べば）履歴を、1 つのファイル（JSON）に書き出せる
- そのファイルを読み込んで戻せる。読み込む前に「置き換える」か「足す」かを選べる

**受け入れ基準**：書き出したファイルを、別の端末やブラウザで読み込むと、同じ「よく使う言葉」と声の設定になる。

### F6 オフライン・ホーム画面
- ホーム画面に追加でき、アプリのように全画面で開く（PWA）
- 一度開けば、電波がなくても開いて話せる（端末に入っている声の場合）
- ホーム画面に追加していないときは、追加をすすめる（iPhone の Safari は、ホーム画面に追加していないサイトの保存データを 7 日使わないと消すことがあるため）

**受け入れ基準**：機内モードで、ホーム画面から開いて話せる。

### F7 見せるモード
- いま打っている文、または最後に話した言葉（履歴からも選べる）を、画面いっぱいの大きな文字で表示する
- 文字の大きさは、画面に収まる最大に自動で合わせる（短い言葉ほど大きい）
- 向かいに座った相手が読めるように、上下を反転できる
- 表示したまま「もう一度話す」ができる。閉じるとすぐ元の画面に戻る
- 入力欄の横と、履歴の各行（押して話したあと、下に出る操作）から開ける

**受け入れ基準**：「はい」なら 1m 離れても読める大きさになる。100 文字の文もはみ出さずに全部表示される。開く・閉じるはそれぞれ 1 タップ。

## 5. 非機能要件

| | 要件 |
|---|---|
| 速さ | 開いてから話せるまで 1 秒以内（2 回目以降）。ボタンを押してから声が出るまでに、アプリ側の待ちを入れない |
| プライバシー | 話した内容・設定はすべて端末の中だけに置く。サーバーへの送信・解析・広告は一切しない |
| 対応環境 | iPhone の Safari（iOS 17 以降）、Android の Chrome、PC の Chrome / Edge / Safari |
| 操作のしやすさ | ボタンは 44px 以上。片手で使える。文字は 16px 以上、入力欄は 20px |
| 見やすさ | ライト／ダークは端末に合わせる。コントラストは WCAG AA 以上。動きを減らす設定を尊重する |
| 支援技術 | VoiceOver / TalkBack で、すべてのボタンに名前がある |
| データ | 保存はブラウザ（localStorage）。消えたときのために F5 で戻せる |
| 費用 | 無料。サーバーを持たない（GitHub Pages の静的サイト） |

## 6. 制約

- 声は端末に入っている声（Web Speech API）に限る。キャラクターの声や、自分の声をまねた声は使えない
- 声の種類・質は端末と OS によって違う。iPhone は最初に読み上げるとき、ユーザーの操作（タップ）が要る
- オンラインの声（例：Chrome の「Google 日本語」）は、電波がないと使えない

## 7. v2 以降の候補（v1 ではしない）

- **呼び出し音**：ピンポンと鳴らして振り向いてもらう（場面 B の騒がしい場所向け）
- **打っている途中の合図**：「いま打っています」と伝えて待ってもらう
- 予測変換（よく使う言葉・履歴からの候補）
- 定型文の差し替え部分（「〇〇まで行ってください」）
- 相手の声を文字にする

## 8. 対象外

- 利用者 C・D への対応（スイッチ操作、視線入力、絵や記号で選ぶ入力）
- 電話での利用
- キャラクターの声・自分の声の再現（ネイティブアプリかサーバーが要る）
- ネイティブアプリ（ロック画面・ウィジェットなど）

## 9. 画面の構成（v1）

スマホで使う前提。画面全体はスクロールさせず、履歴だけがスクロールする（チャットと同じ）。

```
┌──────────────────────────┐
│ echo                    [⋯] │ ← メニュー：書き出し・読み込み・ホーム画面に追加・履歴を消す
├──────────────────────────┤
│ 履歴（古い→新しい。新しいものが下）│ ← ここだけスクロール。開くと一番下（最新）
│              10:52           │    15 分以上あいたら時刻
│          ( 店内で飲みます )  │    吹き出しを押すともう一度話す
│       ( カードでお願いします ) │    操作は最後に話した行の下に出る
│  [☆よく使う言葉に][⛶見せる][✕消す]│
├──────────────────────────┤
│ [返事][あいさつ][お店]…  [✎][▾] │ ← 場面（横スクロール）・編集・たたむ
│ [これをください][カードで払え…]→│ ← よく使う言葉：2 段の横スクロール（1 タップで話す）
│ [いくらですか？][袋はいりません]→│
│ ┌──────────────────────┐ │
│ │ ここに打って「話す」         │ │ ← 入力欄（下に固定）
│ │ (Kyoko・0.9×)    [⛶][話す] │ │
│ └──────────────────────┘ │
└──────────────────────────┘
```

- よく使う言葉の編集（追加・書き直し・並べ替え・削除、場面の追加・名前変更・削除）は ✎ から開く別の画面で行う。普段の画面には出さない
- ▾ でよく使う言葉をたたむと、履歴を広く使える（たたんだかどうかは覚えておく）
- PC（幅が広くマウスのとき）は、よく使う言葉を横スクロールではなく折り返して並べる
